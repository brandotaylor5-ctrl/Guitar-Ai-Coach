# Live Coach v3

This iteration makes Live Coach the product rather than a post-session analyzer.

- Organizes live context as Note / Chord / Key-Center / Progression / Try This Next.
- Infers a tentative tonal center from recent stable chord detections and labels it as a clue rather than certainty.
- Uses recent harmony to suggest a concrete next chord.
- Keeps phrase-level coaching, voice feedback, motif memory, recall, and one-click playable answers.
- Expands Riff Lab to 16 musical templates across three difficulty levels plus blues scale support.
- Progression playgrounds now play the chord loop, generate a lead that targets chord tones while staying inside the selected scale, and let the player save that lead as a riff.
- Existing listen-to-my-attempt practice feedback remains intact.
